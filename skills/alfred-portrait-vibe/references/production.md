# 制作与验收：一个工程，一条时间线

## 引擎与项目

继续已有项目时先检查运行方法、依赖、composition、媒体和未提交改动。新项目选择足以完成任务的一套引擎；通常用 Remotion，不额外维护等价 Canvas 时间线或 Hypit 合成版本。

复用项目包管理器和锁文件。新工程放进独立目录；不为脚手架清空已有目录。按需准备浏览器、编码器或模型，不因创建视频而安装全部相关工具。

Remotion 技术细节优先读已安装插件里与当前动作对应的文件。使用会话已公布路径；路径失效再用 `rg --files` 在用户目录 `.codex/plugins/cache` 或已知技能根目录查找。优先匹配项目主版本和插件实际安装版本，不把目录排序当作版本判断。

| 当前动作 | Remotion 技能中的资源 |
| --- | --- |
| 新工程与 composition 注册 | `remotion-create/SKILL.md`、`remotion-markup/compositions.md` |
| 动画和场景编写 | `remotion-markup/SKILL.md`、`remotion-markup/sequencing.md` |
| 字幕与实测语音时间 | `remotion-captions/SKILL.md` |
| 本地字体 | `remotion-markup/local-fonts.md` |
| Studio / 导出命令 | `remotion-studio/SKILL.md`、`remotion-render/SKILL.md` |

只为实际任务读对应技术文档，不把整个 Remotion 总路由和所有模式带进每个项目。项目版本不支持的可编辑接口不直接照搬。

## 9:16 构图与 3:4 信息安全区

默认竖屏为 1080×1920。将 3:4 解释为画布中居中的信息窗口，并在左右各保留至少 10% 画布宽度；这不是把成片裁成 3:4。

在该画幅下默认安全窗口宽 864、高 1152，左上角为 (108, 384)，范围为 x=108–972、y=384–1536。背景、氛围和非必要装饰可铺满 1080×1920。

标题、字幕、关键数字、标签、主要演示结果、行动提示，以及理解因果所必需的物件/动作，均安排在窗口内。文字与窗口边缘再留适当内边距，避免贴线。产品整页可作环境，但要读清或操作的关键区域必须进安全区。

首个分镜的四张代码模板都显示相同的安全窗口和留边供用户比较选择。目标平台有按钮、标题、头像或底栏模板时，用实际遮挡范围进一步内缩/调整，不能把通用 10% 当成所有平台都安全的保证。用户改留边时同步更新窗口尺寸并保持 3:4 比例。

实现时统一保存画布尺寸和 `safeRect`，构图、字幕与主要运动从同一安全区定位。检查推近、旋转、抖动、出入场和运镜后的实际边界，不能只看静止终态；不要仅用裁切把越界的重要信息藏掉。

确认阶段给带辅助线的检查版，正式交付移除辅助线。其他画幅单独确认安全区，不照搬竖屏坐标或直接裁切。

## 配音确定分镜时间

先由用户选定声音并确认完整配音，再测量实际音频时长和语句区间。Breeze TTS2 返回时间戳时保留原始 `word_timestamps` 或对应部署提供的对齐数据，检查单位、字符/词粒度、停顿及与最终音频的匹配；不能直接当作已核验的分镜时间。缺少时间戳或需要更细的动作事件时用对齐/转写工具，并人工核对关键事件。按实际录音而非估算字速定时。

精确分镜至少记录 `{shotId, audioStart, audioEnd, timelineStart, timelineEnd, duration, events}`，单位明确。音频片段可连续跨镜头，镜头内也可以有多个语句；以语义和视觉理解为拆分依据。

使用同一张表派生字幕、配音片段和动作，确保没有遗漏、意外重叠或重复语句。句尾停顿、额外留白和转场重叠显式入表；转场不无故吞掉语音或压缩阅读时间。

为关键数字、单位、圈注、箭头、公式和逐笔完成定义词级事件；事件标识含句 ID 与重复词的出现序号，不能只搜索字面上的第一次匹配。对齐结果不稳定时核听相邻语段并修正定位，不为工具方便删改文案。

声音、语速、文案或停顿改变后，重新测量受影响区间并更新后续镜头，等待用户确认新版配音/时间表。配乐与音效响应已确认的配音节奏，不用强行卡拍改变叙述速度。

## 让时间可追踪、可重现

- 动画随视频帧推进。Remotion 用 `useCurrentFrame()` 和项目配置的 fps；Canvas 用可重复求值的 `seek(t)`。避免依赖实时时钟、CSS 自运行动画或未固定种子的随机数。
- 统一保存镜头起点、持续时间和关键事件。声音从“镜头起点＋事件偏移”定位；调整顺序后能跟着移动，不散落裸绝对帧号。
- 秒与帧在统一边界转换并明确取整。旁白、画内表演和外部视频先量实际时长，再安排其覆盖画面。
- 有意独立编辑的场景、片段和字幕保留清楚的源节点与参数。参数化实际要修改的内容，不把每个实现细节都暴露成控制项。
- 素材放在项目可解析位置，远程资源在渲染前落实可用性。字体、音频、视频和图片加载完成后再采样，避免预览与导出差异。

## 缓存与局部重做

缓存放在当前工程中，用可核验清单记录输入指纹、采用版本、输出路径、实际时长/尺寸与状态，不只凭文件名存在就认定有效。复用现有引擎的缓存能力；确需补充时只在项目实现必要的分段机制，不再维护一套等价渲染引擎。

| 对象 | 缓存需考虑的输入 | 变化后的处理 |
| --- | --- | --- |
| 配音/试听 | 原文、服务与模型版本、voice_id 或参考音频哈希、语言、语速、情绪/指令及影响生成的参数 | 重新生成受影响语义段，核听并测量，更新相应字幕和后续时间偏移 |
| 镜头画面 | 公共绘制代码与本镜代码、数据、素材/字体、风格、安全区、尺寸/fps、影响本镜的局部事件 | 重渲受影响镜头及相邻转场；公共依赖变化时使全部有关镜头失效 |
| 混音与封装 | 被采用的画面、音轨、裁切、增益、时间表及编码设置 | 只改配乐/增益且画面无变化时可复用画面重混；核查实际输出同步 |

分段配音按自然句群/段落保持韵律，不强制每个短句独立合成。风格或文案更改后重新判断受影响范围，不承诺换全局字体仍可只重渲一镜。镜头只在全片中平移时可复用有效局部画面，合成起点和声音事件仍需重排与检查。

当前引擎不支持某种增量方式时如实采用可用的分段/全片导出，不声称已有秒级缓存或已安装第三方缓存工具。所选流程的确认节点继续有效，重用技术结果不代表新版配音/分镜已经获用户确认。

## 预览与导出

在用户确认进入样片阶段后开启动态预览。Remotion 可从项目运行 `npx remotion studio --no-open`，打开实际返回地址。先验证代表性镜头，等用户确认样片后再铺全片。

局部修改先渲受影响段或静帧确认，再在需要时导出全片。Remotion 的 still、render、composition ID 和参数选项以项目 CLI 帮助与匹配版本文档为准。批量参数通过文件传递，避免 shell 内联 JSON 引号错误。

只要求预览时无需最终编码；完整成片先给全片预览，等用户确认后导出正式文件。临时预览可以编码为可播放文件供判断，不视为已获全片内容或正式交付批准。MP4 编码、分辨率和帧率按用途与素材决定；完成后用 ffprobe 或等价工具核对实际输出，不只检查文件存在。

## 声音设计与同步

1. 先定旁白、原声、环境、音乐和动作声各自的职责。先保证语音可懂，给音乐适当衰减；纯字幕片让声音帮助感知变化与空间。
2. 根据画面动作、材质、强度和时长选音效。高密度小动作可以合并成一段声音；保留必要安静，避免相同长尾叠成噪声。
3. 目标事件与声音文件的开头不一定相同。测量/试听实际语义落点，按需要裁剪、淡入淡出和限长；录音最大峰不自动等于动作起点。
4. 精确卡点时使用：`播放起点 = 目标事件时间 − 音源内语义落点 − 实测输出偏移`。输出偏移按实际编码管线测量，不套用其他项目的帧数。
5. 只有节拍驱动的片子才建立拍点网格并检查误差。普通讲解优先意思和阅读时长，不强迫每次切镜卡鼓点。
6. 镜头时长、顺序、速度或音源变化后，复核受影响声音。导出后复听关键事件；要求精确同步时从实际输出音轨测量。

需要搜索音效时，先确认当前环境有没有可用的音效检索脚本（本技能**不自带**）。有就沿用其检索/获取/分析接口；没有就用现有可用的音频工具自行处理，或请用户提供素材，如实说明缺口。只有候选需求就给候选和试听入口，不下载整库。保留所用素材许可与必要署名要求。

**B5 按需：** 代码合成 BGM 或扩展音效库在用户选择且有需要时启用。先做短段试听，在动态样片节点一起确认；用当前项目的音频工具实现并随工程保留参数/种子，不自动增加整套音乐工作站、固定曲目或大量声音资源。已有配乐及必要动作声不受该可选开关限制，仍按分镜设计。精确卡点不能改变已确认配音的叙述节奏。

## 可核实的验收

以实际画面和声音作判断，不把代码检查、波形或测量结果冒充观看/听感。

| 检查 | 观察什么 |
| --- | --- |
| 意图与内容 | 分镜的核心信息得到表达；产品功能和关键事实有依据 |
| 可理解性 | 观众认得主体、看得到动作、读得出比较与因果；结论有证据 |
| 字幕与布局 | 字体加载、对比、换行、3:4 信息窗口、左右留边、平台遮挡、裁切；关键文字与主要动作运动中也不越界，缩到目标观看尺寸仍可读 |
| 运动与连续性 | 入场、落定、退出与相邻转场；没有闪帧、误跳、突兀循环或错误帧序 |
| 声音 | 使用用户确认的音色和录音；逐镜时长、字幕和动作对齐实际配音，切点与尾音自然，无明显削波与意外静音 |
| 输出 | 实际时长、宽高、帧率、音视频流和开头/结尾符合交付范围 |

先用全片关键帧总览检查风格与信息推进，再看原尺寸的入场、中途、落定帧；可疑转场查看连续片段/逐帧序列。检查“要说明的变化是否真的发生”，避免只截漂亮终态。重要文字和动作在运动中也要留在 3:4 安全区，单位不能被圈注、荧光笔、字幕或图层遮住。

已有布局检查/OCR工具可辅助检查越界、重叠，以及关键数字、单位、引用与源数据的对应；不要把 OCR 误读当成事实依据，也不为每条片强制安装新 OCR 工具。机器检查通过仍要看实际图像与听实际声音。

记录问题的镜头 ID、时间点、可见现象和修复目标。修复后在相同时间点比较，并复查其依赖/邻接片段。完整成片在可播放和可听条件下从头检查；受环境限制时说明覆盖范围与未核实项。不规定最低/最高修改轮数，也不为已通过的无关部分反复全量检查。

## 交付与继续修改

交付请求范围内的成片，以及源代码、必要媒体、依赖锁定和运行/导出方法。记录采用版本、素材路径、未解决问题和重要事件，确保之后能从当前状态续做。凭据不进入交付包。

多画幅需要重新检查布局；不把横屏简单裁切当作竖屏适配。无 BGM 版、单独音轨、字幕文件、透明视频和剪辑软件专有工程仅在需要时生成。

B3 双语和 B4 档案复原的呈现细节见视觉指南，均只在采用后制作并随样片验收。B6 已从制片流程移出：不额外生成发布标题、话题、运营数据复盘，也不向已确认视频开头自动插入封面帧。

普通自检是制作过程的一部分。独立评审仅在用户要求或实际复杂度需要且具备授权时使用，不强制每条小视频增加多代理和重复报告。
