# 量化闸门：不合格就不交片

本技能的原则是「宁可报错，也不要静默失败」。这份文件把「感觉不够好」换成可判定的数字，规定哪些数字不达标时**不许往下走**。

机器过检不等于可以交片。闸门只拦得住能算的东西；看得懂、听得舒服仍然要人看人听。

## 什么时候跑什么

| 阶段 | 脚本 | 不过怎么办 |
| --- | --- | --- |
| 第 3 步文案定稿后 | `density.py` | 报告给用户，不擅自改文案；改不改由用户定 |
| 选 B5 合成 BGM 后 | `bgm.py` → `beats.py --bpm N` | BPM 对不上先修，别拿错的拍点排片 |
| 第 7 步动态样片后 | `qa.py` | 有 FAIL 就修，修完重跑 |
| 第 8 步全片交付前 | `qa.py` | **有 FAIL 不交付** |

**本技能不提供音乐驱动的时间表工具。** 分镜时长由已确认配音的实际时长决定，不按音乐小节排。配乐只响应已确认的配音节奏，不用强行卡拍改变叙述速度。需要拍点信息时用 `beats.py` 查，不要拿它反推镜头时长。

## qa.py：成片闸门

```bash
python scripts/qa.py final.mp4 plan.json \
  --size 1080x1920 --fps 30 --anchor 3 12 27 -o qa
```

| 检查 | FAIL 条件 | 说明 |
| --- | --- | --- |
| 规格 | 分辨率或帧率不等于声明值 | 声明值来自第 1 步记录的画幅 |
| 时长 | 实际与计划差 > `--tol`（默认 0.15s） | 差得多说明渲染丢了帧或时间表没落实 |
| 音轨 | 没有音频流且未加 `--silent` | 纯字幕片必须显式声明，不许默认放过 |
| 黑帧 | 存在 ≥0.10s 且像素 <10% 的黑场 | 转场黑场属正常时，在计划里写明并接受 WARN |
| 削波 | 音频峰值 ≥ −0.1 dBFS | 削波是不可逆的，必须回去降增益 |
| 出图 | 不判定 | 联络表和锚点帧必须人看 |

`--anchor` 给的是「必须精确切在某一帧」的屏。它输出切点前一帧和后一帧，两帧应当分别是旧画面和新画面；如果两帧一样，切点错位。

**看图的顺序**：先看 `sheet-*.jpg` 总览（风格是否统一、有没有哪屏明显空），再逐张看原尺寸（字号、重叠、辉光吃掉的字），最后看锚点前后帧（切点对不对）。

## density.py：文案体检

```bash
python scripts/density.py 字幕.txt --duration 128 --genre film
```

`--genre film` 是稀疏字幕片（默认）：≥2.6 字/秒、≥11 句/分、单句 ≤28 字。
`--genre dense` 是高密度解说：≥7.0 字/秒、≥20 句/分、单句 ≤20 字。

| 报什么 | 意思 | 处理 |
| --- | --- | --- |
| `[密度]` 字/秒过低 | 观众觉得讲得太少 | 删氛围句，过渡并进下一句，补事实或数字 |
| `[节奏]` 句/分过低 | 节奏拖 | 拆句，或缩短整片时长 |
| `[句长]` 超长 | 一屏读不完 | 拆成两句，各配一个屏上动作 |
| `[口播腔]` 命中填充词 | 「众所周知」「说白了就是」 | 出现即删 |
| `[车轱辘话]` 相邻重复 | 两句说同一件事 | 合并，或让下一句推进论点 |

**这个脚本只诊断，不改文案。** 用户给定的文案保留原意和口吻；把问题指出来，改不改由用户决定。

## beats.py：拍点

```bash
python scripts/beats.py music.mp3 --bpm 77 --json beats.json
```

**已知陷阱：自动检测有八度错误。** 检测器的偏好中心在 120 BPM，77 BPM 的曲子会被判成 154 BPM，小节线随之全部翻倍。脚本在检测值 >140 或 <90 时会打印警告。

| 情况 | 做法 |
| --- | --- |
| 自己用 `bgm.py` 合成的配乐 | **必须** `--bpm` 给合成时的值 |
| 已知 BPM 的现成配乐 | 直接 `--bpm` |
| 完全未知 | 先跑自动检测，看到警告就用 `--bpm 检测值/2` 复核一遍 |

核对方法：`fit` 那行的 mean error 应在 5ms 以内；`小节线` 间隔应等于 4×拍长（4/4 拍）。间隔不对就是 BPM 错了。

## bgm.py：配乐合成

```bash
python scripts/bgm.py bgm.wav --bpm 77 --duration 140 --key Am \
  --sections "0,8,pad;8,30,piano;30,90,full;90,105,arp;105,120,piano;120,140,outro"
```

纯 numpy 合成，无采样、无虚拟乐器。76–78 BPM 小调，峰值 −1dB。织体级别：`pad`（只有铺底）< `piano`（进钢琴）< `full`（进打击）< `arp`（琶音突出）< `outro`（回落）。

只有用户明确选了 B5 才用。已有配乐时不生成新曲，不强制固定 BPM。

## 闸门的边界

- 机器查不出「观众看不看得懂」。联络表上每一屏都要自己回答：这是什么？它做了什么？因此明白了什么？
- 安全区越界目前靠人看，不做自动判定。锚点帧和原尺寸帧要确认关键文字和数字在 3:4 窗口内。
- 修完必须重跑，并且在**相同时间点**重截对比；只看新图看不出「改好了一处、改坏了另一处」。
- 受环境限制跑不了某一项时，如实说明覆盖范围和未核实项，不假装通过。
