# 知识讲解：让观众看见原因

## 给概念找形象

按最直接的路径找表达，不把所有题材都翻译成抽象点线。

| 概念是什么 | 优先呈现 |
| --- | --- |
| 一个真实物件 | 可识别的本体、尺度与必要特征 |
| 一个过程或算法 | 足够小、能逐步走完的真实例子 |
| 一个量或程度 | 同一把尺子下的数量、长度、面积或概率 |
| 一个直觉或认知偏差 | 让观众先做一次短判断，再揭晓 |
| 一条规律 | 几个可比较例子，再把共同关系摆出来 |
| 一个总结或提问 | 停留已有证据、简洁文字或必要留白 |

数学、文字、网络等题材本身需要数轴、表格、点线或图表时可以直接使用；判断标准是观众能否认出它们代表什么、读出真实关系。

## 让论证在画面里发生

- 字幕说“吸附”，屏上确实接触并附着；说“减半”，观众看得到同一尺度下的变化。名词和动词都应有画面依据。
- 先呈现例子，再引出名字、公式和结论。用重复出现的道具或尺度降低观众重新理解的成本。
- 让观众知道物件在哪里、大小如何、与自己有什么关系，再进入微观或抽象层。
- 因果链保留中间步骤。需要跨尺度时，用可追踪的物体或位置连接变化。
- 不为每句话增加新场景。比较需要并置，演化需要连续，结论可以停住，提问可以留白。
- 字幕按自然语义分组，并与标题、关键数字和主要演示动作一起放入已确认的 3:4 信息窗口；声音和字幕可以并用，不强制一行或固定读秒。镜头时长跟随用户已确认的实际配音。

一个最小分镜示例：

| 文案 | 主体与动作 | 观众理解 |
| --- | --- | --- |
| 同样一杯水，倒进不同形状的杯子 | 固定水量依次倒入矮宽杯与细高杯，保留同一刻度参照 | 水位改变不等于水量改变 |
| 先别看水位，比较总量 | 两杯倒回同样的量杯，液面重合 | 用合适的尺度判断 |

## 事实与自检

对上屏的关键数字、人物、年份和机制保留来源。易变化、专业或不能确定的事实先核实；查不到的删改或明确标为假设。图形里的计数、比例和单位从同一数据生成，避免字幕与画面各写一份。

科学示意可简化，但需要保留正在解释的机制；会引起误解的简化注明“示意”。真实数据与为解释构造的示例分开标记。

对数字密集、概率或算法内容，先从来源/计算得到结果，再让图形与文字共用这一份数据。需要展示多次试验时预先用固定种子算出状态并按时间回放；计数器、比例、曲线和结论对应同一过程，不用装饰性随机波形冒充试验。

保留单位、分母、假设及必要的简化说明。关键计算检查边界、总量、比例或单调性等与论点相关的性质；只有实际需要时才写验证脚本。用户文案与核实结果冲突时，指出具体句子、值与依据，请用户处理该问题，不修改数据迎合文案，也不增加整篇文案确认。

逐镜问：这是什么？它做了什么？因此观众明白了什么？无法回答时回到形象或因果链修改。只靠标签才认得出的真实物件，需要改造型、上下文或取材方式。

同一物体或尺度跨镜头回场，逐步累积新的关系；遇到对照、机制、结论时分别选择并置、逐步执行或停留，不强制所有文案套进同一开场钩子、历史段落或固定时长骨架。只在有实际收益时使用视觉指南中的逐笔、圈注和剖面组件。
